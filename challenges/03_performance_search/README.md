# Challenge 3: The Search Optimizer

## Context
A critical part of our system needs to find common elements between two lists of data. The current implementation works for small lists, but when faced with large data volumes, its performance degrades drastically, causing timeouts. The problem lies in the algorithmic inefficiency of the function.

## Your Task
Optimize the find_common_elements function in solution.py. You must reduce its computational complexity so it can process large lists in a fraction of a second. The solution does not require a complex algorithm but rather the clever use of Python's built-in data structures.

> Note: The starter implementation is intentionally inefficient.
